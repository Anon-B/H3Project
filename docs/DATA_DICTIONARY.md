# Data Dictionary

## datasets
| Field | Meaning |
|---|---|
| dataset_id | Unique dataset ID |
| name | Unique dataset name |
| data_type | point/multipoint/line/multiline/polygon/multipolygon/geometry_collection/raster/mixed |
| h3_resolution | Canonical source H3 resolution, 5..15 |
| metadata | Dataset configuration JSONB |
| source | Source/provenance |
| owner | Data owner |
| version | Dataset version |
| source_format | Source format |
| geographic_coverage | Coverage metadata JSONB |
| tags | Dataset tags |
| license | Usage/license metadata |
| update_frequency | Expected update cadence |
| schema_definition | Source schema JSONB |
| lineage | Data lineage JSONB |

## entities
| Field | Meaning |
|---|---|
| entity_id | Unique entity ID |
| dataset_id | Owning dataset |

## entity_attributes
| Field | Meaning |
|---|---|
| entity_id | Entity reference |
| properties | Source Entity attributes as JSONB |

## entity_parts
| Field | Meaning |
|---|---|
| part_id | Spatial part ID |
| entity_id | Parent entity |
| part_index | Order inside entity |
| part_type | point/line/polygon |
| min_lat/max_lat | Part bbox latitude |
| min_lng/max_lng | Part bbox longitude |
| properties | Reserved part-level JSONB |
| metadata | Reconstruction/storage metadata |

## entity_part_h3
| Field | Meaning |
|---|---|
| part_id | Spatial part |
| resolution | H3 resolution |
| ring_id | Ring identifier |
| ring_type | none/outer/hole/line |
| h3_index | H3 cell ID |

## entity_point
Exact latitude/longitude for point entities.

## ingestion tables
- ingestion_runs: pipeline execution summary.
- ingestion_parts: source feature/part audit mapping.
- ingestion_h3_cells: generated H3 audit rows.

## raster_datasets
Stores raster dataset metadata and external file URI. It is future-facing for raster ingestion.

## Compatibility
`entity_h3` view exposes entity_id, resolution and h3_index from entity_part_h3.

## Important distinction
Boundary H3 is canonical. Display H3 cells generated by frontend are derived visualization state and are not a database field/table.
